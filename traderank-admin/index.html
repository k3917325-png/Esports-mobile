🛡 Admin Login

Sirf admin account se login hoga.
Admin kaise banayein?
1) App mein ya Firebase Authentication mein ek account banao.
2) Firebase Console → Authentication → Users se uska UID copy karo.
3) Firestore Database mein collection admins banao, document ID = wahi UID (koi bhi field, jaise role: "admin").
4) Ab us email/password se yahan login karo.
